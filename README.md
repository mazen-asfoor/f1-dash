<h1>Welcome to the F1FM Analytics session analysis app!!</h1>

The free to use website offers a various collection of analytical tools and graphs that are used by F1 teams themselves all for free online!
This is a personal project (my first) inspired by my drive to understand race stratigies and overall performance of F1 cars and power units.

<h3>Main Features and Pages</h3>
  <ol>
    <li><b>The Pace Analysis Page:</b> Acts as a summary for the session with graphs and statistics that deliver a broad vision of the whole session as a whole. It includes an average pace boxplot, driver consistency (using standard deviation of filtered data) and top speed bar charts, top 20 fastest laps with driver, team, lap number and  tyre age, percentage of the fastest car on track (Teams) and the time difference to race leader across each lap.</li>
